# Lottie animations

The uploaded Lottie JSON files are preserved as source files for future conversion.

GitHub profile READMEs do not render raw Lottie JSON as animations. Use a rendered GIF or WebP preview and reference it from the profile README, for example:

```html
<img src="./assets/animation.gif" width="160" alt="Animated illustration">
```

The source animations should be rendered with a Lottie-compatible renderer (such as lottie-web) before being embedded.
